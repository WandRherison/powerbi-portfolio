SYS.05 // PERGUNTAS FREQUENTES

Respostas diretas.

O que recrutadores, líderes técnicos e parceiros costumam perguntar antes da primeira conversa.

Você está disponível para estágio, vaga júnior ou projetos freelance em BI e Dados?

Sim. Estou cursando Análise e Desenvolvimento de Sistemas (UNISAL, conclusão em 2026) após passagem pelo Itaú Unibanco como Jovem Aprendiz, e estou aberto a posições de estágio, analista de dados/BI júnior e projetos sob demanda.

Os dados exibidos nos dashboards do portfólio são reais ou simulados?

O projeto Padaria Diniz opera sobre arquitetura real com MySQL na AWS RDS e Views mascaradas (LGPD), refletindo as métricas exatas do painel publicado. Os cases de Adega, ONGs, PetShop e Supply Chain utilizam datasets sintéticos gerados em Python com integridade referencial estrita para demonstrar cenários corporativos realistas.

Por que o projeto da ONG Clube Gringas exibe apenas prints e nenhum código?

Por ser um projeto real em ambiente de produção de uma organização sem fins lucrativos, adoto sigilo rigoroso sobre código-fonte, URLs internas e dados de associadas, apresentando exclusivamente capturas visuais sanitizadas.

É possível baixar os arquivos .pbix, scripts Python e Views SQL de LGPD?

Sim. Todos os arquivos .pbix, scripts Python (generate_*.py), CSVs e o script views_powerbi_lgpd.sql dos projetos de BI estão públicos no repositório WandRherison/powerbi-portfolio.
